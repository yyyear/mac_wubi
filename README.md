# 四方五笔（macOS）

四方五笔是基于 Swift 和 InputMethodKit 的原生 macOS 输入法。一个系统输入源提供五笔 86、全拼和拼音五笔混合三种方案。查词和词库导入都在本机完成。
使用 AI 开发。暂时使用没有什么问题。

## 安装与首次输入

1. **安装或升级**：运行 `四方五笔-0.3.3.pkg`。安装包写入系统目录 `/Library/Input Methods/`，并尝试为当前用户启用四方五笔，不强制切换输入源。如果以前从源码安装到了用户目录，请在原位置升级，避免同时保留两份。
2. **选中输入法**：从 macOS 状态栏的输入法菜单选择「四方五笔」。若菜单中没有，到「系统设置 → 键盘 → 输入法（编辑…）→ ＋ → 简体中文」添加；列表中仍找不到时，注销后重新登录再试。
3. **试打**：再次打开状态栏输入法菜单，选择「只拼音」。在文本框输入 `nihao`，看到「你好」后按对应数字上屏。

## 从状态栏切换方案

四方五笔启用时，打开状态栏输入法菜单，**用鼠标点击，或用 ↑ / ↓ 选中后按回车**。带 ✓ 的是当前方案；「偏好设置…」也从这个菜单打开。**从 0.3.1 起，方案切换和打开偏好设置都不绑定快捷键**，旧版自定义的方案快捷键不再生效。选词、翻页和中英文切换按键不受影响。

| 菜单项 | 如何输入 |
| --- | --- |
| 只五笔 | 使用五笔 86 编码，如 `wqiy` →「你」。可开启四码唯一候选自动上屏。 |
| 只拼音 | 输入全拼，如 `chongqing` →「重庆」。用 `v` 表示 ü，用英文单引号分隔音节。 |
| 拼音五笔混合 | 同一串编码同时查五笔和拼音，候选去重；不会在第四码自动上屏。支持逐词输入，不是整句组句，也不在同一个词里混拼两种编码。 |

切到不同方案时，尚未选词的编码会按原文上屏。要丢弃这段编码，先按 Esc。

### 输入时常用的按键

| 操作 | 按键或方式 |
| --- | --- |
| 选词 | 每页从 1 重新编号。空格选当前页第一个，`1`–`9` 按序号选择，`0` 选第 10 个，也可用鼠标点选。 |
| 翻页 | ← / →、Page Up / Page Down；有上一页或下一页时也可用逗号 / 句号。 |
| 编辑编码 | Delete 删最后一个字符；Esc 取消；回车按原文上屏。 |
| 中英文切换 | 默认单击 Shift 或按 Shift + 空格；待输入的字母保留大小写。例如按 Shift + A，再输入 `b`，单击 Shift 会上屏 `Ab` 并切到英文。 |

## 偏好设置

在状态栏输入法菜单中选择「偏好设置…」。修改后自动保存，无需重启。**「输入」页只显示当前方案；每页候选数在「候选」页调整。**

| 分类 | 可以做什么 |
| --- | --- |
| 输入 | 查看当前方案，设置四码唯一自动上屏（仅五笔）和拼音模糊音。 |
| 词库 | 选择拼音或五笔编码，导入本地词表。 |
| 候选 | 设置每页数量（默认 5，范围 1–10）、候选上限（8–256）、前缀候选、续码提示、候选词的完整五笔编码和学习排序。 |
| 标点 | 设置中文标点，以及是否用 Shift + 标点输入英文标点。 |
| 中英文 | 设置 Shift、Shift + 空格切换以及光标旁的切换提示。 |
| 按键说明 | 查阅输入、选词、翻页等按键；这是速查表，不是快捷键编辑器。 |
| 关于 | 查看版本、打开配置文件夹、清除用户词频或恢复默认设置。 |

在「候选」页可关闭完整五笔编码。例如用简码 `wq` 找到「你」时，其下方会显示 `wqiy`；编码提示不会随选词上屏。如果本机字体缺少某个生僻字的字形，候选窗会显示它的 Unicode 码点（如 `U+27763`），选中后仍输入原字。

**模糊音示例：**在「输入 → 模糊音」开启 z/zh 后，`zongguo` 也能找到「中国」，准确拼写的候选优先。默认开启 z/zh、c/ch、s/sh、an/ang、en/eng、in/ing；n/l、f/h、l/r 可按需开启。模糊音只影响拼音和混合方案。

## 导入自己的词库

在「偏好设置 → 词库」选择**词条的编码类型**（拼音或五笔），再点「选择文件…」。这里的选择决定导入到哪个词库，不会切换当前输入方案。导入会合并相同编码与词条，不覆盖内置词库。

| 文件格式 | 要求 |
| --- | --- |
| UTF-8 `.tsv` / `.txt` | 每行依次为编码、词条、可选权重，以 Tab 分隔。 |
| Rime `.dict.yaml` | 每条记录须有显式编码；不自动展开 `import_tables`。 |
| 搜狗拼音 `.scel` | 仅可导入拼音词库。 |

单文件上限 16 MiB，每类词库最多 30 万条。若检测到本机清歌公共拼音词表，页面还会显示专用导入按钮，不读取个人学习记录。

**试一遍：**选择「拼音」，导入[自定义拼音词库示例](Examples/自定义拼音词库.tsv)，再用拼音或混合方案输入 `sifangwubi` →「四方五笔」。也可以导入[日常拼音快输词表](Examples/日常拼音快输.tsv)，用 `mywt` 输入「没有问题」。

## 配置、卸载与排查

- **找配置和数据**：状态栏菜单 →「打开配置文件夹」。默认位置为 `~/Library/Application Support/WubiInput/`；`config.json` 保存设置，`userfreq.tsv` 保存学习词频。如果只是想让候选恢复字典原序，选择「清除用户词频」即可，无需删除词库。
- **学习记录何时写盘**：选词后，本次学习立即参与候选排序。第一次有变化后约 30 秒，输入法在后台一次写回这段时间的词频；持续打字不会推迟写回，没有新记录时不写。正常退出会补写，强制结束或断电可能丢失最近一批学习记录，不影响已经上屏的文字。
- **安装后看不到，或升级后仍像旧版**：先从源码目录运行 `./Scripts/doctor.sh` 检查安装位置、签名和系统是否收录。确认只安装了一份后，若输入源未启用，可运行 `./Scripts/repair-input-sources.sh`；它只检查并按需启用四方五笔，不切换当前输入源。菜单仍未刷新时，注销后重新登录，不必反复安装。
- **卸载**：从源码目录运行 `./Scripts/uninstall.sh`。脚本移除输入法程序，保留用户配置、导入词库和学习记录。

## 从源码试用、构建与分发

构建目标为 macOS 13 及以上，使用支持 Swift 5.9 或更高版本的 Xcode 工具链。在项目根目录运行：

```bash
swift test                        # 运行测试
swift run wubi-cli type wqiy wubi # 仅在命令行试打，不改变系统输入源
swift run wubi-preview            # 图形预览，不必安装
```

按需要选择一种安装或分发方式，不要依次执行：

| 目的 | 命令 | 结果 |
| --- | --- | --- |
| 仅为当前用户安装 | `./Scripts/install.sh` | 安装到 `~/Library/Input Methods/`。 |
| 为所有用户安装 | `./Scripts/install.sh --system` | 安装到 `/Library/Input Methods/`，需要管理员权限。 |
| 生成安装包 | `./Scripts/build_pkg.sh` | 在 `build/` 下生成带版本号的 `.pkg`，不执行安装。 |

默认构建不会为安装包做 Developer ID Installer 签名或公证。持有 Developer ID Application 和 Installer 证书时，可用 `./Scripts/build_pkg.sh --sign` 签名；面向外部分发时还需单独提交公证。
